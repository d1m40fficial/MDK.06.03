# AGENTS.md: репозиторий spo-it-materials

Сайт со всеми дисциплинами техникума. Работай по локальному скиллу
`.opencode/skills/course-studio/SKILL.md`: это объединённый скилл Course Studio +
Anatomy + Visualise, он описывает план дисциплин, написание занятий, построение фигур и
сборку сайта. Прочитай его перед любой задачей про курсы, лекции, практики, схемы,
фигуры, план дисциплины или сборку сайта.

## Что где лежит

- `courses/<year>/<slug>/course.json`: план дисциплины (карточка, результаты, занятия,
  поле `"assessment"` со значением «Зачёт» или «Экзамен», поле `"code"` с официальным
  кодом вроде `ОП.01` или `МДК.03.01`).
  Годы: `courses/2/`, `courses/3/`, `courses/4/`.
- `courses/3/mapo/`: МАПО, 32 занятия и 64 ч, 15 лекций и практики на 17 занятий,
  часть практик по 180 минут. Число занятий фиксировано; баланс лекций и практик
  меняется только по запросу.
- `courses/4/uifis/`: УФИС, 42 занятия и 84 ч.
- `courses/4/db-automation/`: МДК.07.01, 29 занятий и 66 ч, MySQL в XAMPP,
  phpMyAdmin, .NET SDK 10 и Visual Studio 2022.
- `courses/4/is-certification/`: МДК.07.02, 18 занятий и 42 ч.
- `courses/4/is-implementation/`: МДК.06.01, 38 занятий и 88 ч, внедрение ИС
  от обследования до приёмки и сопровождения.
- `courses/4/is-support/`: МДК.06.02, 38 занятий и 88 ч, поддержка, SLA,
  инциденты, мониторинг и сопровождение ИС.
- `courses/4/demo-exam-2027/`: ДЭ-2027, 8 разделов и 40 ч: общая информация,
  шесть методичек по заданиям КИМ 09.02.07-5-2027 и 30 вариантов для практики
  по материалам `OlgaKraven/2027-dkip-demo`.
- `courses/<year>/<slug>/chapters/<nn-slug>/`: занятие: `chapter.md` + `figures/<fig-id>/`.
- `site.json`: специальности и карточки курсов для landing.
- `availability.txt`: сколько лекций и практик открыто для каждой дисциплины.
- `docs/`: сгенерированный сайт. **Не редактировать вручную**: правь источники и запускай
  `python tools/build_site.py` (на Windows сначала `$env:PYTHONUTF8=1`).
- `_reference/miapo/`: старые личные заметки, в git не входят; только опорный материал
  для сверки, публиковать их нельзя.
- `.opencode/skills/course-studio/`: объединённый скилл; `anatomy/` внутри него: движок
  фигур, `references/visualise/`: лёгкие SVG/HTML-схемы.
- `tools/new_discipline.py` и `tools/worktree.py`: дисциплина и её отдельный worktree.
- `tools/ks/scripts/availability.py`: читает `availability.txt` и решает, какие главы
  открыты.

## Специальность и ДЭ 2027

Репозиторий обслуживает специальность 09.02.07 «Информационные системы и
программирование», квалификация «Специалист по информационным системам». Актуальный
демонстрационный экзамен: КИМ 09.02.07-5-2027, БОМ 6506,
https://bom.firpo.ru/Public/6506.

- ПА, 1 ч 10 мин: ER-диаграмма в 3НФ в PDF, база данных с таблицами и ограничениями,
  импорт JSON, SQL-запрос с JOIN и агрегацией.
- ГИА базовый уровень, 3 ч 30 мин: те же три задания, модули ИС (авторизация,
  блокировка, смарт-капча, CRUD пользователей, уникальность, интерфейс), GET API с
  обработкой данных, коллекция Postman с тестами 200, 500 и валидации JSON,
  документация API по шаблону.
- Компетенции: ПК 2.2-2.4, 5.1-5.4, 7.1-7.4, 11.1-11.5 и ОК 01, 02, 04, 09.
- Доступное ПО: Excel, Word, PowerPoint, VS Code с Python, Visual Studio 2022
  Community с рабочей нагрузкой .NET desktop, .NET SDK 10, Postman, XAMPP 8.5.12
  (MySQL/MariaDB и phpMyAdmin), VirtualBox с учебными Linux и Windows 10, браузер с
  draw.io, sqliteonline.com, GitHub, Kaggle, Colab и Google Docs. MySQL для
  МДК.07.01 работает из XAMPP, отдельный сервер MySQL или PostgreSQL не требуется.
  Не требовать PlantUML, StarUML, Enterprise Architect, Visio, PyCharm, отдельный
  сервер MySQL или PostgreSQL и платные сервисы.
- Настройки учебных ПК ограничены администратором. Лабы по ОС и системным настройкам
  выполняются в VirtualBox; не требовать прав администратора, host-only сети или
  изменений Windows на хосте. Для SSH использовать NAT и проброс порта.
- Каждая практика должна давать артефакт для ДЭ: ER в PDF, скрипт БД, SQL-скрипт,
  работающее приложение, коллекцию Postman, документ Word или презентацию.

## Главные правила

- Одна дисциплина = одна папка `courses/<year>/<slug>/` + своё поле `"year"` в `course.json`.
  Дисциплина с `"format": "cards"` не делится на лекции и практики: её план это карточки
  разделов, а страницы разделов собираются тем же движком.
- В учебном плане сначала идёт лекция, которая вводит тему, затем практика по этой
  теме. Практика не может стоять перед лекцией, где впервые объясняются её понятия.
- Название практики не повторяет название лекции: берите смежную тему, применение
  или другой пример. В описаниях занятий нет конструкций «Студент ...», «Сдаёт ...»:
  используйте безличные формы или прямое обращение.
- В критериях практик шкала 1-5: 1 за работу с ИИ или копирование без права
  исправления, 2 за невыполненную работу, 3-5 за качество выполнения.
- В практиках нет абсолютных путей с буквой диска: только относительные пути
  вида `.../папка/файл` или имя команды.
- Перед критериями оценки в практике идёт чек-лист выполнения: таблица «Пункт»,
  «Сделано», «Осталось». Шаги не сворачиваются и не получают отдельных чекбоксов.
- Практика не даёт готовых ответов в таблицах: сырые данные, пустой шаблон или
  одна строка-образец. Новая команда сначала разбирается на примере.
- Если практика опирается на учебную ИС или набор данных, к занятию приложены
  файлы, архив или шаблон отчёта.
- Все DOCX-шаблоны отчётов оформляются по единому шаблону: A4, поля 3 см слева,
  1,5 см справа, по 2 см сверху и снизу, Times New Roman 14 пт, интервал 1,5,
  отступ первой строки 1,25 см, заголовки Heading 1 и Heading 2, таблицы Table Grid
  с шапкой по центру, название таблицы под таблицей.
- Каждая дисциплина разрабатывается в своём worktree и ветке `discipline/<year>/<slug>`,
  чтобы агенты работали параллельно. Готовую ветку вливают в `main` перед публикацией.
- Сайт генерируется: landing (специальности, внутри годы) → год (список дисциплин) →
  дисциплина (план) → занятие. Не правь `docs/` вручную.
- 09.02.07 раскрывается в годы 2, 3 и 4. Специальности 09.02.12 и 09.02.13 пока пустые,
  без предметов.
- В карточке дисциплины показываются часы, число занятий и система оценивания. Статус
  `available` даёт «Доступно», статус `planned` даёт «Не готово» и лёгкую прозрачность.
- Фигуры: движок Anatomy (`anatomy/`) для главной фигуры занятия, Visualise
  (`references/visualise/`) для лёгких схем, таблиц, графиков и виджетов. Excalidraw не
  используем: старые диаграммы заменяем на Anatomy/SVG (при необходимости 3D).
- Фигуры Anatomy и SVG-схемы всегда остаются в светлой теме, даже если страница
  переключена в тёмную.
- Никаких длинных тире и одиночного дефиса как тире в текстах, `course.json`, брифах и
  подписях фигур. Это проверяют сборка главы и `check_pages.py`.
- Доступность занятий задаётся в `availability.txt`: занятие с номером больше
  указанного не собирается в `docs/` и помечается в плане как закрытое.
- Практика может занимать 90 или 180 минут. Практика на 180 минут считается двумя
  занятиями, но общее число часов не меняется. Объёмные практики объединяют, чтобы
  уменьшить число оценок и не дробить работу. Уже написанную практику не объединяй без
  переноса её текста.
- В тексте занятия не указывай общее время выполнения и минуты рядом с шагами.
  Длительность хранится в `course.json` и показывается в карточке и плане.
- В названиях, описаниях и текстах занятий не упоминай демонстрационный экзамен.
  Дисциплина и занятие самостоятельны; экзамен это итог обучения, а не тема карточки.
- Лекция разбита на 2-4 смысловых блока директивами `::gate Вопрос?` и `::/gate`.
  Кнопка стоит после законченной мысли и задаёт вопрос о следующем блоке, а не пишет
  «Продолжить». Первый блок с главной фигурой виден сразу, тест входит в последний
  блок. Ворота не вкладывают друг в друга, каждый закрывается `::/gate`.
- Каждая лекция заканчивается тестом `::quiz` из 15 вопросов по материалу лекции:
  от 6 до 10 вопросов с одним ответом (`+` и `-`), от 2 до 4 с несколькими
  правильными ответами (несколько `+`), от 1 до 3 с кратким ответом (одна или
  несколько строк `=`). У каждого вопроса есть пояснение `!`. В тексте лекции не
  перечисляй, сколько и каких вопросов в тесте. Практики тест не получают. Сборка
  предупреждает, если вопросов не 15 или отсутствует один из типов.
- Вопросы теста открываются по одному, каждый новой карточкой ниже предыдущей, и
  следующая карточка появляется сразу после ответа на прошлый вопрос, без кнопки
  «Следующий вопрос». После ответа показываются верный вариант и пояснение `!`;
  пояснение показывается и при верном ответе. После последнего ответа встроенная
  карточка показывает ФИО, результат, время выполнения теста и время просмотра
  лекции, без кнопки сдачи. Не добавляй `Проверить ответы`, `Сбросить`, `Сдать
  работу` или собственную форму сдачи.
- Кнопки перехода к занятиям скрыты, пока в лекции остаются закрытые ворота, и на
  лекции с тестом появляются только после карточки результата.
- При прокрутке занятия нижние блоки мягко появляются снизу. Анимация включается
  через IntersectionObserver, не скрывает первый экран и отключается при
  `prefers-reduced-motion`.
- Рейка управления одна на весь сайт и стоит у левого края. На занятии это стрелка
  назад к учебному плану, экспорт в PDF, предупреждение о сбросе прогресса (только в
  лекции) и переключение тёмной темы. На странице учебного плана вместо PDF стоит
  экспорт плана в Excel, на странице года только стрелка назад и тема, на главной
  только тема. Кнопки домика нет. Стрелка есть на всех страницах кроме главной,
  подпись у неё «Вернуться обратно»; на занятии она ведёт к учебному плану, на плане
  к списку дисциплин года, на странице года к главной. Это общий движок `_pages.py`,
  `build_course.py`, `build_chapter.py` и `notes.css`; не дублируй рейку в
  `chapter.md`.
- Учебный план выгружается в Excel файлом `Учебный_план_<название предмета>.xlsx`
  через `plan_xlsx.py`: таблица с номером, типом, темой, минутами, содержанием и
  ключевыми понятиями, с итоговой строкой. PDF на странице плана не нужен.
- Не коммить `_reference/` и личные заметки; не трогай `courses/_anatomy/` руками.

## Частые команды

```powershell
$env:PYTHONUTF8=1
python tools/build_site.py                 # собрать сайт в docs/
python tools/new_discipline.py 3 otp --title "..." --code "ОТП"
python tools/worktree.py add 3 otp         # только worktree
python tools/ks/scripts/build_chapter.py courses/4/uifis/chapters/01-lek-01/chapter.md
```

Перед коммитом: `python tools/build_site.py`, затем
`python tools/ks/scripts/check_pages.py courses/<year>/<slug>/dist` и `git diff --check`.
Проверка сама раскрывает `::gate`, чтобы увидеть скрытые фигуры и разделы.
Сборка детерминирована, поэтому повторный запуск не должен менять `docs/`.

# 4 курс

Дисциплины четвёртого курса. Сейчас здесь УФИС (МДК.06.03): папка `uifis/` с
`course.json`, главами, отчётами и фигурами.

Новая дисциплина создаётся командой из корня репозитория:

```powershell
$env:PYTHONUTF8=1
python tools/new_discipline.py 4 <slug> --title "<Название>" --code "<КОД>"
```

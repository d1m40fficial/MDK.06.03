## Цель работы

Научиться превращать знание системы в занятие для конкретной роли. Вы выбираете группу сотрудников «Северного склада», пишете программу из четырёх блоков, готовите памятку и упражнение на учебной ИС, проводите занятие в мини-группе и собираете обратную связь. Результат работы не конспект, а комплект материалов и вывод о том, что в нём пришлось исправить после первого показа.

## Оборудование и программное обеспечение

- Компьютер с Windows 10 или 11 и браузером.
- Учебная ИС «Склад+» на стенде XAMPP: MySQL и phpMyAdmin запущены, база с тестовыми данными доступна.
- Учебные учётные записи ролей: менеджер, кладовщик, администратор. Пароли выдаёт преподаватель.
- Word для программы и памятки, Excel для листа обратной связи и сводки, PowerPoint по желанию для первого слайда.
- draw.io, если нужна схема экрана вместо скриншота.
- Тестовые данные: три клиента, шесть товаров, остатки по двум складам. Набор выдаётся вместе с заданием.

**Комплект «Склад+».** [Скачать архив](reports/kit/sklad-plus-kit.zip) и распаковать в папку работы. Внутри: `app/index.html` (учебный прототип, открывается в браузере), `database/schema.sql` и `database/seed.sql` (импорт в phpMyAdmin), `data/` (CSV и JSON для импорта), `templates/` (шаблоны отчётов). Демо-доступы прототипа: `admin / admin`, `manager / manager`, `storekeeper / storekeeper`.

## Краткие теоретические сведения

Обучение строится вокруг роли, а не вокруг возможностей системы. Менеджеру по продажам нужны заказ, резерв и статусы, кладовщику нужны задание на комплектацию, приёмка и расхождения. Если посадить их в одну группу, половина времени уйдёт на чужие операции, а внимание упадёт.

Группа обучения собирается по трём признакам: одинаковый набор операций, одинаковые права и похожий уровень. Рабочий размер группы для практикума от шести до десяти человек. В такой группе ведущий видит руки каждого, а участник успевает сделать операцию сам, а не смотреть, как это делает сосед.

Программа обучения состоит из блоков. Каждый блок заканчивается действием участника и проверяемым результатом: человек вошёл в систему, оформил заказ, увидел отказ по остатку, снял резерв. Блок, в котором участник только слушает, считается потерянным.

Упражнение на учебной ИС берёт реальный сценарий из практики компании. В нём есть конфликт: товара не хватает, склад закрыт, клиент просит отгрузку частями. Именно конфликт заставляет искать решение, а не повторять кнопки по памяти.

Обратная связь собирается вопросами о понятности материала, а не об обаянии ведущего. Хороший вопрос звучит так: «На каком шаге вы не поняли, что делать дальше?» Плохой вопрос звучит так: «Вам понравилось занятие?» Первый даёт правку в памятку, второй даёт вежливую улыбку.

## Ход работы

### Шаг 1. Выберите роль и группу

Возьмите одну роль из кейса. Сведения для решения собраны в отделе кадров и в анкете, которую сотрудники заполнили перед внедрением.

| Роль | Человек | Смен | Средний стаж | Что чаще спрашивают |
|---|---|---|---|---|
| Менеджер по продажам | 24 | 2 | 5 лет | где резерв и почему заказ не сохраняется |
| Кладовщик | 31 | 2 | 8 лет | как принять поставку с расхождением |
| Бухгалтер | 6 | 1 | 11 лет | почему не сходится выгрузка |
| Закупщик | 4 | 1 | 6 лет | как оформить заявку поставщику |
| Администратор ИС | 2 | 1 | 3 года | права и справочники |

Соберите группу по трём признакам из теории и запишите решение в таблицу. Первая строка дана как образец, остальные заполните сами: роль, состав группы, главная операция и обоснование в одну фразу.

| Роль | Группа для занятия | Главная операция | Обоснование |
|---|---|---|---|
| Бухгалтер | Г2, 4 человека, офис Москва, уровень средний | сверка платежей | 6 человек, одна смена, ошибки выгрузки дороже всего |
| | | | |

Роль с численностью два человека в группу не берут: на двух участниках не проверить ни темп, ни типовые запинки.

### Шаг 2. Составьте программу обучения

Соберите четыре блока. В каждом блоке укажите, что разбираете, что участник делает руками и какой результат считается достигнутым.

Материал для программы: операции роли из шага 1, вопросы из анкеты и три запинки, которые наставники слышат чаще всего: «не находит нужный раздел», «не проверяет склад в шапке», «не читает сообщение системы». Первый блок дан как образец, остальные три постройте сами.

| Блок | Что разбираем | Действие участника | Результат блока |
|---|---|---|---|
| 1. Рабочее место | вход, выбор склада, разделы меню | входит и открывает свой раздел | видит только свой склад |
| 2. | | | |
| 3. | | | |
| 4. | | | |

Проверьте пропорцию: показ занимает примерно пятую часть занятия, остальное время участники работают. Если в программе три блока из четырёх состоят из рассказа, программу нужно переписать.

### Шаг 3. Подготовьте раздаточный материал

Сделайте памятку на одну страницу. Каждый шаг начинается с глагола, называет поле и показывает, что должно появиться на экране.

Разобранный пример для другой операции, вход в систему:

```text
1. Откройте адрес учебной ИС в браузере. Появится форма входа.
2. Введите логин и пароль своей роли. В поле «Склад» выберите свой город.
3. Нажмите «Войти». В шапке появятся фамилия и название склада.
```

Три шага показывают устройство шага: действие, поле, видимый результат. По этому образцу напишите 5-7 шагов для главной операции своей роли, с теми названиями полей и кнопок, которые видите на экране.

Рядом сделайте карточку ошибок. Возьмите запинки из шага 2 и добавьте те, что заметите на занятии. Для каждой ошибки укажите признак, по которому её видно, и правильное действие.

### Шаг 4. Соберите упражнение на учебной ИС

Возьмите сценарий с конфликтом. Клиент ООО «Стройбаза Тула» заказывает 40 мешков цемента и 12 листов OSB. На складе Тулы цемента 25 мешков, OSB хватает. Участник должен оформить заказ, увидеть нехватку и выбрать решение: отгрузить 25 мешков сейчас, остаток перенести, предупредить клиента.

| Шаг упражнения | Действие | Ожидаемый результат |
|---|---|---|
| 1 | создать заказ на клиента | номер заказа присвоен |
| 2 | добавить цемент, 40 мешков | система показывает нехватку 15 |
| 3 | | |
| 4 | | |
| 5 | | |
| 6 | | |
| 7 | | |

Первые два шага даны как образец. Дальше распишите сами, что участник делает с нехваткой, как добавляет вторую позицию, чем заканчивает заказ и как проверяет результат.

Проверьте упражнение сами до занятия. Если на четвёртом шаге система не даёт изменить количество, значит, сценарий не готов, а участники потратят время на борьбу с интерфейсом.

### Шаг 5. Проведите занятие в мини-группе

Соберите группу из трёх-четырёх человек. Один участник ведёт занятие, второй работает наблюдателем, остальные выступают пользователями. Потом роли меняются, чтобы каждый попробовал себя в роли ведущего.

Ведущий показывает первый шаг на экране, дальше участники повторяют сами. Мышь и клавиатуру у участника никто не забирает: подсказка идёт словами, а не чужими руками.

Наблюдатель держит чек-лист и отмечает, нашёл ли участник раздел, выбрал ли склад, увидел ли остаток, обработал ли нехватку, сохранил ли заказ, повторил ли операцию без памятки. Каждая запинка записывается с номером шага, иначе правка получится наугад.

### Шаг 6. Соберите лист обратной связи

Раздайте лист из пяти закрытых вопросов и одного открытого. Шкала от 1 до 5, где 5 значит «полностью понятно». Два вопроса даны как образец, остальные три закрытых и один открытый допишите под свои блоки.

| Вопрос | Что показывает |
|---|---|
| Понятно, с какого раздела начать работу | качество первого блока |
| Понятно, что делать при нехватке товара | качество третьего блока |
| | |
| | |
| | |
| | открытый ответ |

Соберите не меньше четырёх заполненных листов. Посчитайте средний балл по каждому вопросу и выпишите открытые ответы дословно: в них чаще всего и лежит настоящая причина запинки.

### Шаг 7. Разберите результаты и поправьте материалы

Сведите замечания из чек-листа наблюдателя и открытых ответов в таблицу и покажите, что именно изменили. Первая строка дана как образец, остальные заполните по своим записям. Материал без правки после первого показа считается несданным, потому что первая группа всегда находит слабое место.

| Замечание | Что правлю | Версия |
|---|---|---|
| не видно, что склад меняется в шапке | добавил скриншот шапки со стрелкой | 1.1 |
| | | |
| | | |
| | | |

Закончите отчёт выводом на полстраницы: что сработало, что пришлось переписать, какую правку вы бы сделали в следующий раз. Вывод пишется по наблюдениям, а не по ощущениям: ссылайтесь на номера шагов и средние баллы.

## Критерии оценки

Оценка выставляется по шкале от 1 до 5.

| Оценка | Условие |
|---|---|
| 5 | Работа выполнена полностью и самостоятельно, все пункты ниже выполнены |
| 4 | Работа выполнена, есть 1 или 2 незначительных замечания |
| 3 | Работа выполнена частично, есть существенные замечания |
| 2 | Работа не выполнена |
| 1 | Работа выполнена с использованием ИИ или скопирована полностью или частично, 1 балл без возможности исправления |

Что проверяется:
- Выбор группы обоснован ролью, числом людей и уровнем.
- В программе четыре блока, каждый заканчивается действием участника.
- Памятка содержит 5-7 шагов с полями и результатом.
- Упражнение содержит конфликтный сценарий и таблицу ожидаемых результатов.
- Занятие проведено, участники работали сами, наблюдатель вёл записи.
- Обратная связь собрана с четырёх листов и сведена в таблицу.
- Правки внесены по замечаниям, версия материалов указана.

Работа без проведённого занятия или без заполненных листов обратной связи возвращается на доработку.

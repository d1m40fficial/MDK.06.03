## Цель работы

Научиться превращать журнал обращений в набор метрик поддержки: объём, время реакции, время решения, доля первой линии, повторные обращения и соблюдение SLA. Собрать сводную таблицу, построить графики, сформулировать выводы и предложения для сервисного менеджера.

Результат работы это книга Excel с четырьмя листами и короткий вывод на листе «Выводы»: какие показатели в норме, какие вышли за норму и что предложить заказчику.

## Оборудование и программное обеспечение

- Компьютер с Windows 10 или 11 и браузером.
- Excel или LibreOffice Calc.
- Файл журнала обращений, таблица приведена в шаге 1.
- Word для оформления вывода, если преподаватель требует текстовый файл.

## Краткие теоретические сведения

Метрика это число, которое считается по одному правилу для всех периодов. Если правило меняется от месяца к месяцу, сравнивать показатели нельзя.

Время реакции считается от регистрации обращения до первого ответа пользователю. Время решения считается от регистрации до момента, когда работа выполнена и подтверждена. Точку отсчёта фиксируют один раз.

Среднее арифметическое чувствительно к выбросам: одно обращение на двое суток поднимает среднее по всему месяцу. Медиана это значение в середине упорядоченного ряда, она показывает типичное обращение. 90-й процентиль показывает значение, ниже которого находится 90 процентов обращений, и именно его используют в SLA.

Соблюдение SLA считается как доля обращений, уложившихся в срок. Для «Северного склада» действуют нормы: критический инцидент 4 часа, высокий 1 рабочий день или 8 часов, обычный 3 рабочих дня или 24 часа, первый ответ 15 минут.

Доля первой линии показывает, какая часть обращений закрыта без передачи на вторую линию. Повторное обращение это заявка по той же проблеме от того же пользователя в течение тридцати дней.

### Шаг 2. Проверьте данные

До расчётов проверьте журнал: заполнены ли ячейки времени, нет ли ответа раньше регистрации и повторяющихся номеров. Результат каждой проверки запишите в протокол.

| Что проверить | Как проверить | Результат | Найдены проблемы |
|---|---|---|---|
| лишние пустые строки в конце листа | прокрутить лист до последней записи | пустых строк нет | нет |
| число строк | =СЧЁТЗ(Журнал!A2:A25) | | |
| ответ не раньше регистрации | =(C2-B2) и =(D2-B2) по всем строкам | | |
| уникальность номеров | =СЧЁТЕСЛИ(Журнал!A2:A25;A2) и протянуть вниз | | |
| формат даты и времени | выравнивание ячейки и вид записи в строке формул | | |

Если проверка не прошла, исправьте данные до формул: метрика по грязному журналу врёт.

### Шаг 3. Посчитайте время реакции и решения

Добавьте два столбца. Время реакции считайте в минутах, время решения в часах.

```text
I2: =(C2-B2)*1440
J2: =(D2-B2)*24
```

Протяните формулы до строки 25. Столбец I отформатируйте как число с одним знаком после запятой, столбец J как число с двумя знаками.

Проверьте строку 2 вручную: реакция 11 минут, решение 1,2 часа. Если формула дала другое, проверьте формат ячеек: текст вместо даты даёт ошибку.

### Шаг 4. Добавьте нормы и признак выполнения

Норма зависит от приоритета. Добавьте столбец K «Норма, ч» и столбец L «В срок».

```text
K2: =ЕСЛИ(E2="критический";4;ЕСЛИ(E2="высокий";8;24))
L2: =ЕСЛИ(J2<=K2;"да";"нет")
```

Для времени реакции добавьте столбец M «Ответ в срок» с формулой =ЕСЛИ(I2<=15;"да";"нет").

В рабочем журнале незакрытые обращения нельзя считать выполненными в срок.

### Шаг 5. Сведите объём и приоритеты

На листе «Сводка» постройте таблицу объёма. Число обращений считайте функцией СЧЁТЗ, распределение по приоритетам функцией СЧЁТЕСЛИ.

```text
Всего обращений: =СЧЁТЗ(Журнал!A2:A25)
Критических:    =СЧЁТЕСЛИ(Журнал!E2:E25;"критический")
Высоких:        =СЧЁТЕСЛИ(Журнал!E2:E25;"высокий")
Обычных:        =СЧЁТЕСЛИ(Журнал!E2:E25;"обычный")
Первой линией:  =СЧЁТЕСЛИ(Журнал!G2:G25;1)
```

| Показатель | Формула | Значение | Норма | Отклонение |
|---|---|---|---|---|
| всего обращений | СЧЁТЗ | | около 30 в неделю | |
| критических | СЧЁТЕСЛИ | | не больше 5 процентов | |
| высоких | СЧЁТЕСЛИ | | не больше 30 процентов | |
| обычных | СЧЁТЕСЛИ | | остальное | |
| закрыто первой линией | СЧЁТЕСЛИ | | 65 до 75 процентов | |

### Шаг 6. Посчитайте среднее, медиану и 90-й процентиль

На листе «Сводка» добавьте блок распределения времени решения.

```text
Среднее:          =СРЗНАЧ(Журнал!J2:J25)
Медиана:          =МЕДИАНА(Журнал!J2:J25)
90-й процентиль:  =ПЕРСЕНТИЛЬ.ВКЛ(Журнал!J2:J25;0,9)
Максимум:         =МАКС(Журнал!J2:J25)
```

В английской версии Excel функция называется PERCENTILE.INC. Если её нет, отсортируйте значения по возрастанию и возьмите номер, равный 0,9 умножить на число строк, с округлением вверх.

Сравните среднее и медиану. Если среднее заметно больше медианы, в журнале есть хвост медленных обращений. Найдите эти строки и выпишите их номера.

### Шаг 7. Посчитайте SLA, долю первой линии и повторы

Соберите блок качества.

```text
В срок:            =СЧЁТЕСЛИ(Журнал!L2:L25;"да")
Доля SLA:          =СЧЁТЕСЛИ(Журнал!L2:L25;"да")/СЧЁТЗ(Журнал!A2:A25)
Ответ в срок:      =СЧЁТЕСЛИ(Журнал!M2:M25;"да")/СЧЁТЗ(Журнал!A2:A25)
Доля первой линии: =СЧЁТЕСЛИ(Журнал!G2:G25;1)/СЧЁТЗ(Журнал!A2:A25)
Повторные:         =СЧЁТЕСЛИ(Журнал!H2:H25;"да")/СЧЁТЗ(Журнал!A2:A25)
```

Результаты приведите в процентах с одним знаком после запятой. Нормы: SLA не ниже 95 процентов, ответ в срок не ниже 95 процентов, первая линия 65 до 75 процентов, повторные не выше 10 процентов.

Отдельно посчитайте SLA по приоритетам. Критический инцидент с нарушением срока важнее десяти обычных, поэтому общая доля без разбивки скрывает проблему.

| Приоритет | Всего | В срок | Доля | Вывод |
|---|---|---|---|---|
| критический | | | | |
| высокий | | | | |
| обычный | | | | |
| итого | | | | |

### Шаг 8. Постройте графики

Постройте три диаграммы на листе «Графики».

1. Столбчатая диаграмма числа обращений по дням с 1 по 6 октября. Подпишите ось «Дата», ряд «Число обращений».
2. Линейчатая диаграмма распределения по приоритетам. Покажите, что критических обращений меньше всего.
3. Гистограмма времени решения с интервалами 0 до 1, 1 до 2, 2 до 4, 4 до 8 и больше 8 часов. Для неё добавьте столбец «Интервал» и посчитайте частоты функцией СЧЁТЕСЛИМН.

Гистограмма показывает хвост, которого не видно в среднем: обращения дольше 8 часов дают повод для вывода.

### Шаг 9. Сформулируйте выводы и предложения

На листе «Выводы» напишите пять пунктов: число, норма, вывод. Нулевая строка показывает формат записи и взята из другого отчёта.

```text
0. Образец: загрузка инженеров 78 процентов при норме не выше 80, отклонения нет.
1. Объём: ___ обращений за 6 дней, это около ___ в неделю при норме 34.
2. Скорость: медиана решения ___ часа, 90-й процентиль ___ часа.
3. Сроки: SLA выполнен в ___ процентах случаев при норме 95.
4. Качество: повторных ___ процентов при норме 10.
5. Загрузка: ___ обращений длились больше 8 часов.
```

Число в выводе без нормы ничего не значит: рядом стоит, сколько должно быть.

Предложения формулируются от причины, а не от показателя. «Повысить SLA» не предложение. Нужна запись с действием, эффектом и сроком, например «сократить согласование заявок на доступ до одного дня, ввести шаблон заявки».

## Критерии оценки

Оценка выставляется по шкале от 1 до 5.

| Оценка | Условие |
|---|---|
| 5 | Работа выполнена полностью и самостоятельно, все пункты ниже выполнены |
| 4 | Работа выполнена, есть 1 или 2 незначительных замечания |
| 3 | Работа выполнена частично, есть существенные замечания |
| 2 | Работа не выполнена |
| 1 | Работа выполнена с использованием ИИ или скопирована полностью или частично, 1 балл без возможности исправления |

Что проверяется:
- Журнал перенесён без ошибок, форматы даты и времени корректны.
- Время реакции и решения посчитано формулами, а не вручную.
- Нормы по приоритетам заданы формулой, признак выполнения посчитан.
- Среднее, медиана и 90-й процентиль посчитаны и объяснены.
- SLA, доля первой линии и повторные обращения сведены в таблицу.
- Графики построены, гистограмма показывает хвост.
- Выводы содержат числа, нормы и предложения по причинам.

Работа без формул возвращается на доработку: ручные значения нельзя пересчитать.

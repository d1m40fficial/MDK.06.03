# V30 · Производство чайных наборов

Мастерская «Листок» выпускает продукцию «Подарочный набор чая» по спецификациям. Магазин «Листок-1» заказал 30 ед. к 22.03.2027. Менеджер оформляет заказ, технолог задаёт состав, мастер планирует выпуск. Требуется связать документы в одной информационной системе и рассчитать нормативную стоимость заказа.

## Производственный процесс

Дозирование → фасовка в пакеты → сборка коробки.

## Правила учёта

Набор содержит три сорта чая по 50 г; нормы приведены на весь набор. Нормы заданы на одну единицу готовой продукции. Материалы: количество выпуска × норма × цена. Операции: количество выпуска × часы × тариф за час. Цены действуют с 01.03.2027, НДС, наценка, доставка и дополнительные накладные расходы не учитываются. Промежуточные суммы не округлять, итог округлить до копеек.

Авторский учебный вариант по структуре базового КИМ 09.02.07-5-2027. Не официальный экзаменационный вариант. 6 заданий, 210 минут, 75 баллов. Все организации и данные учебные.

Материалы и операции в спецификации различаются значениями material и operation. Время указано только для операций. Поле addres в JSON сохранено как имя входного поля. Пользователи manager, technologist и master — обычные пользователи, административную запись создайте отдельно.

## Задание 1

По документам Мастерская «Листок» спроектируйте ER-диаграмму в 3НФ. Отразите заказчиков, продукцию «Подарочный набор чая», спецификации с материалами и операциями, цены и производственный заказ. Для каждого документа определите реквизиты и повторяющиеся строки. Укажите PK, FK, кратности; сохраните PDF.

## Задание 2

Создайте базу для Мастерская «Листок» в выбранной СУБД по вашей схеме. Импортируйте все 6 записей Заказчики.json, сохранив ведущие нули кодов. Загрузите заказ V30-01, спецификацию и цены из Excel. Проверьте внешние ключи, сделайте выгрузку и восстановите её в пустую базу.

## Задание 3

Создайте SQL-запрос нормативной стоимости заказа V30-01 предприятия Мастерская «Листок»: 30 ед. продукции «Подарочный набор чая». Набор содержит три сорта чая по 50 г; нормы приведены на весь набор. Нормы заданы на одну единицу готовой продукции. Материалы: количество выпуска × норма × цена. Операции: количество выпуска × часы × тариф за час. Цены действуют с 01.03.2027, НДС, наценка, доставка и дополнительные накладные расходы не учитываются. Промежуточные суммы не округлять, итог округлить до копеек. Покажите материалы и операции отдельными строками и общую сумму.

## Задание 4

Создайте приложение Мастерская «Листок»: Windows Forms + MySQL либо WPF + PostgreSQL. Реализуйте вход по логину, паролю и пазлу, роли Администратор и Пользователь; третья подряд ошибка пароля или пазла блокирует запись. Администратор добавляет и изменяет пользователей, снимает блокировку. Проверьте пустые поля, дубли логинов и обработку ошибок. Используйте изображения и требования приложения к заданию 4.

## Задание 5

Реализуйте API заметок сотрудников Мастерская «Листок». Создайте users и notes со связью автора, внесите 5 записей из Заметки.json, сопоставив логины существующим пользователям. GET /notes или /api/notes возвращает id, title_user («title - login»), content без изменений, formatted_date (ДД.ММ.ГГГГ). Проверьте 200, пустой массив, 400 для неверного запроса и 500 при сбое БД. Сохраните коллекцию с исполняемыми проверками HTTP-кодов и JSON.

## Задание 6

Документируйте API заметок Мастерская «Листок» в исходном шаблоне DOCX из приложения к заданию 6. Через Swagger UI выполните реальный запрос и перенесите его ответ в документ. В OpenAPI проверьте пути, параметры, поля и типы ответа. Укажите URL, реализованные методы, форматы, примеры 200, пустого результата, 400 и 500. Сохраните DOCX, OpenAPI JSON и тестовую коллекцию.

## Результаты

ER PDF, SQL и выгрузка БД, запрос стоимости, проект приложения, проект API и коллекция проверок, DOCX по шаблону, OpenAPI JSON. Приложения к заданиям 4–6 находятся в каталоге «Приложения» архива.

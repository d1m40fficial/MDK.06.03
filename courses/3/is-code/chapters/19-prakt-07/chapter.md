## Цель работы

ООО «Северный склад» получает поставки от транспортной компании «ТрансЛогистика». Поставщик присылает документ JSON, а справочник товаров бухгалтерия выгружает в CSV. Программа склада должна свести два источника, проверить, что каждый артикул есть в справочнике, отобрать нужные строки и передать результат на площадку в Москве.

Цель работы: написать скрипт на Python, который читает JSON в словарь, читает CSV в список строк таблицы и раскладывает их по словарям, преобразует записи в объекты `SupplyLine`, отбрасывает строки с неизвестным артикулом, фильтрует поставки по площадке и количеству и сохраняет отбор в новый JSON и новый CSV.

Результат работы это скрипт `src/exchange.py`, два входных файла, два выходных файла и отчёт со сверкой количества строк и суммы. Готовых ответов в таблицах нет: данные даны как есть, преобразования нужно выполнить самостоятельно.

## Краткие теоретические сведения

**Обмен данными** это передача записей между двумя системами, у которых разные модели хранения. Внешняя система знает свои идентификаторы, свои единицы измерения и свои правила заполнения полей. Приложение склада знает свои. Задача импорта состоит не в том, чтобы прочитать файл, а в том, чтобы привести чужие записи к своей модели и явно обработать то, что не сходится.

**JSON** хранит объекты и массивы. В Python объект становится словарём `dict`, массив списком `list`, число числом, строка строкой. Для чтения файла используют `json.load`, для записи `json.dump`. Вложенность означает, что поставка содержит список строк, и обходить её нужно двумя вложенными циклами.

**CSV** хранит плоскую таблицу. Модуль `csv` с классом `DictReader` берёт первую строку как заголовок и возвращает словари, где ключи это имена столбцов. Все значения остаются строками, поэтому количество и цену нужно преобразовывать вручную. Разделитель задают параметром `delimiter`, кодировку выбирают при открытии файла.

**Объект программы** это запись, у которой поля имеют понятные имена и типы. Класс `SupplyLine` с полями `number`, `warehouse`, `date`, `sku`, `qty` и `price` отделяет модель склада от формата файла. Если завтра поставщик переименует поле, изменится только функция чтения, а фильтрация и выгрузка останутся прежними.

**Приведение типов** выполняется на границе импорта. Количество становится `int`, цена становится `Decimal`, дата остаётся строкой в формате ISO или преобразуется в `date`. Идентификатор товара остаётся строкой, даже если состоит из цифр: ведущие нули значимы.

**Фильтрация** применяется после приведения типов, иначе сравнение строк даст неверный результат. Условие `qty >= 20` для строки `"12"` и числа `20` может дать неожиданный итог, а для числа работает предсказуемо. Фильтр должен быть записан в отчёте словами, чтобы проверяющий мог повторить отбор.

**Сверка** это проверка, что результат согласован с источником. Сравнивают количество строк до и после фильтра, сумму количеств и сумму стоимости. Если из шести строк отобраны две, а сумма не сходится с ручным расчётом, ошибка в преобразовании или в условии.

### Шаг 2. Прочитайте JSON в словарь

Сначала небольшой пример. Он показывает, как устроен документ после разбора.

```python
import json
from pathlib import Path

path = Path(".../sklad-plus/data/in/supplies.json")

with path.open(encoding="utf-8") as file:
    document = json.load(file)

print(type(document).__name__)
print(list(document))
print(document["supplier"])
print(len(document["shipments"]))
print(document["shipments"][0]["items"][1]["sku"])
```

```text
dict
['supplier', 'sent_at', 'shipments']
ТрансЛогистика
3
SKU-2210
```

`json.load` читает файл целиком и возвращает словарь. Ключ `shipments` содержит список из трёх поставок. Внутри каждой поставки лежит список `items`. Путь `["shipments"][0]["items"][1]["sku"]` читается так: первая поставка, вторая строка, артикул.

Напишите функцию `read_supplies(path)`, которая возвращает список объектов `SupplyLine`. Внутри используйте два цикла: внешний по поставкам, внутренний по строкам. Не обращайтесь к элементам по индексу, если можно перебрать список циклом.

### Шаг 3. Прочитайте CSV в список словарей

Пример чтения CSV с разделителем `;`.

```python
import csv

with open(".../sklad-plus/data/in/stock.csv", encoding="utf-8-sig", newline="") as file:
    reader = csv.DictReader(file, delimiter=";")
    rows = list(reader)

print(reader.fieldnames)
print(rows[0])
print(type(rows[0]["qty"]).__name__)
```

```text
['sku', 'title', 'category', 'qty', 'price']
{'sku': 'SKU-1042', 'title': 'Перчатки нитриловые', 'category': 'Спецодежда', 'qty': '48', 'price': '312,50'}
str
```

`utf-8-sig` убирает BOM, если он есть. `newline=""` отключает преобразование переводов строк, чтобы значения с переносами внутри кавычек читались правильно. `DictReader` возвращает итератор, поэтому `list(reader)` материализует все строки.

Напишите функцию `read_stock(path)`, которая возвращает словарь, где ключ это артикул, а значение словарь с полями `title`, `category`, `qty` и `price`. Количество приведите к `int`, цену к `Decimal`, заменив запятую на точку.

### Шаг 4. Опишите объект SupplyLine

Создайте класс данных с полями `number`, `warehouse`, `date`, `sku`, `qty`, `price`. Добавьте свойство `total`, которое возвращает стоимость строки: цену, умноженную на количество.

```python
from dataclasses import dataclass
from decimal import Decimal

@dataclass
class SupplyLine:
    number: str
    warehouse: str
    date: str
    sku: str
    qty: int
    price: Decimal

    @property
    def total(self) -> Decimal:
        return self.price * self.qty
```

Проверьте объект на одной строке. Создайте его вручную и напечатайте поля и `total`. Убедитесь, что `qty` это целое число, а `price` это `Decimal`, а не строка.

### Шаг 5. Приведите типы при чтении

В JSON количество уже число, но полагаться на это нельзя: внешняя система может прислать `"48"` строкой. Поэтому в `read_supplies` примените `int(item["qty"])`. Цену преобразуйте через `Decimal(str(item["price"]))`, а не через `Decimal(item["price"])`: если поставщик пришлёт число с плавающей точкой, прямое преобразование сохранит двоичную погрешность.

В CSV оба поля приходят строками. Для количества используйте `int(row["qty"])`, для цены `Decimal(row["price"].replace(",", "."))`. Если ячейка пустая, преобразование выбросит `ValueError`. Решите, что делать: пропустить строку с сообщением или считать количество нулевым. Выбор зафиксируйте в отчёте.

Проверьте преобразование на строке с ценой `312,50`. В объекте должно получиться `Decimal("312.5")`, а `total` для количества 48 равно `15000.0`. Если нужен вид с двумя знаками после запятой, примените `quantize(Decimal("0.01"))` при выводе, а не при расчёте.

### Шаг 6. Соедините два источника

Соберите все строки поставок в один список. Затем проверьте, что каждый артикул есть в справочнике.

```python
lines = read_supplies(Path(".../sklad-plus/data/in/supplies.json"))
stock = read_stock(Path(".../sklad-plus/data/in/stock.csv"))

missing = sorted({line.sku for line in lines if line.sku not in stock})
print("нет в справочнике:", missing)
```

Ожидается один отсутствующий артикул. Такие строки нельзя молча выбрасывать: в отчёт попадает артикул и номер поставки. В учебном задании достаточно вывести список, в рабочей системе такую запись сохраняют в отдельный файл ошибок.

После проверки оставьте только строки, у которых артикул есть в справочнике. Соединение выполняйте по ключу словаря, а не вложенным перебором всех строк справочника: при 4800 позициях разница заметна.

### Шаг 7. Отфильтруйте записи

Условие отбора: площадка `Москва` и количество не меньше 20. Сначала запишите условие словами, затем кодом.

```python
selected = [
    line
    for line in lines
    if line.sku in stock and line.warehouse == "Москва" and line.qty >= 20
]
print("после фильтра:", len(selected))
print("сумма отбора:", sum((line.total for line in selected), Decimal("0")))
```

Из шести строк должно остаться две. Проверьте это вручную по файлу: одна строка из первой поставки и одна из третьей. Строка с отсутствующим артикулом не проходит по количеству, но её всё равно нужно показать в отчёте об ошибках, поэтому проверка артикула стоит раньше фильтра.

Если результат не совпал, напечатайте каждую строку с её условиями: площадку, количество и наличие в справочнике. Так ошибка находится быстрее, чем перечитыванием кода.

### Шаг 8. Сохраните результат в JSON и CSV

Для каждой отобранной строки соберите словарь с полями `number`, `date`, `sku`, `title`, `qty` и `total`. Название товара возьмите из справочника, стоимость из свойства объекта.

Запись JSON:

```python
import json

path = Path(".../sklad-plus/data/out/moscow_supplies.json")
with path.open("w", encoding="utf-8") as file:
    json.dump(result, file, ensure_ascii=False, indent=2)
```

Запись CSV:

```python
import csv

path = Path(".../sklad-plus/data/out/moscow_supplies.csv")
with path.open("w", encoding="utf-8-sig", newline="") as file:
    writer = csv.DictWriter(
        file,
        fieldnames=["number", "date", "sku", "title", "qty", "total"],
        delimiter=";",
    )
    writer.writeheader()
    writer.writerows(result)
```

`ensure_ascii=False` сохраняет кириллицу читаемой. `indent=2` делает JSON пригодным для сравнения глазами. В CSV важны `newline=""` и `utf-8-sig`: первый убирает лишние пустые строки на Windows, второй помогает Excel показать русские названия.

Откройте оба файла и проверьте, что в них две строки данных и что заголовок CSV совпадает с `fieldnames`. Если JSON записался одной длинной строкой, проверьте, передан ли `indent`.

## Критерии оценки

Оценка выставляется по шкале от 1 до 5.

- **5**: JSON и CSV читаются с явной кодировкой и разделителем, записи преобразованы в объекты, типы приведены, неизвестный артикул показан, фильтр даёт верные две строки, оба файла записаны и прочитаны обратно, сверка сходится.
- **4**: работа выполнена полностью, но неизвестный артикул только пропущен без сообщения или сумма выведена как `float`.
- **3**: прочитан только один формат, фильтр работает по строковому количеству, выходной файл записан без `newline=""` или без заголовка.
- **2**: работа не выполнена или скрипт не запускается на предоставленных файлах.
- **1**: работа выполнена с использованием ИИ или скопирована полностью или частично, 1 балл без возможности исправления.

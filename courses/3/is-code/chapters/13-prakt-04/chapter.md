## Краткие теоретические сведения

Класс это описание того, из чего состоит объект и что он умеет. Поля хранят состояние: артикул, остаток, ячейку. Методы описывают поведение: списать товар, принять поставку, показать статус. Объект это конкретный экземпляр класса с собственными значениями полей.

Словарь `{"sku": "SKU-1042", "stock": 0}` тоже хранит данные, но не мешает перепутать `stock` и `min_stock`, не проверяет значения и не подсказывает, какие операции допустимы. Класс собирает данные и правила в одно место: остаток меняется только через метод, а метод знает условие склада. Поэтому в модели предметной области класс надёжнее набора словарей.

Конструктор `__init__` вызывается при создании объекта. В нём задают начальные значения полей и проверяют то, что не должно быть пустым. Если конструктор пропускает проверку, объект появляется на свет уже с неверным состоянием, и искать причину позже дороже.

Метод, который меняет состояние, должен сначала проверить условие, а потом менять поле. Если проверка не прошла, остаток остаётся прежним, а вызывающий код получает понятный ответ. Возврат `True` или `False` в методах на этом занятии заменяет исключение: обработку ошибок разберём отдельно, а пока важно не оставить объект в половинчатом состоянии.

Состояние объекта проверяют сразу после вызова, а не в конце сценария. Иначе ошибка в одном методе маскируется другим вызовом, и таблица результатов перестаёт что-либо доказывать. Проверка после каждого шага показывает не только итог, но и момент, когда состояние разошлось с ожиданием.

### Шаг 2. Создайте класс с конструктором

Создайте файл `.../sklad-plus/src/models/product.py`. Ниже каркас класса: конструктор и один готовый метод. Остальные методы добавьте сами.

```python
class Product:
    def __init__(self, sku, name, category, price, stock, min_stock, cell):
        self.sku = sku
        self.name = name
        self.category = category
        self.price = price
        self.stock = stock
        self.min_stock = min_stock
        self.cell = cell

    def status(self):
        if self.stock < self.min_stock:
            return "ниже минимума"
        return "в норме"


product = Product(
    "SKU-2087", "Кабель UTP cat.5e, 305 м", "Электрика",
    8990.00, 12, 4, "D-01-1",
)
print(product.sku, product.name, product.stock, product.status())
```

Запустите файл и сверьте вывод:

```text
SKU-2087 Кабель UTP cat.5e, 305 м 12 в норме
```

Затем создайте второй объект для `SKU-1042` с остатком 0 и минимальным запасом 40. Вызовите `status()` и объясните в отчёте, почему результат отличается. Обратите внимание: имя товара содержит запятую, а разделитель в выгрузке другой, поэтому при разборе строки нельзя делить её по запятой.

Добавьте в конструктор три проверки: артикул не пустой, цена и остаток не отрицательные. При нарушении поднимите `ValueError` с текстом, в котором есть артикул. Пока это единственное место, где объект получает начальные значения, поэтому проверка здесь защищает все дальнейшие вызовы. Убедитесь, что объект с остатком `-1` не создаётся, а объект с корректными данными создаётся и работает как раньше.

### Шаг 3. Добавьте методы изменения остатка

Реализуйте три метода по правилам из шага 1.

- `write_off(qty)` списывает товар. Операция разрешена, только если `qty` больше нуля и не превышает текущий остаток. При успехе метод уменьшает `stock` и возвращает `True`, при отказе не меняет ничего и возвращает `False`.
- `restock(qty)` принимает поставку. Операция разрешена, только если `qty` больше нуля. При успехе метод увеличивает `stock` и возвращает `True`, иначе возвращает `False`.
- `stock_value()` возвращает стоимость остатка: цена, умноженная на количество, округлённая до двух знаков.

Метод `status()` уже показывает пример работы с полями. Новый метод стройте по той же схеме: сначала проверка, потом изменение, в конце возврат результата. Проверьте `write_off` на одном объекте вручную, прежде чем переходить к сценарию.

```python
product = Product("SKU-2087", "Кабель UTP cat.5e, 305 м", "Электрика",
                  8990.00, 12, 4, "D-01-1")
print(product.write_off(5), product.stock)
print(product.write_off(8), product.stock)
```

Ожидаемый вывод для исправного метода:

```text
True 7
False 7
```

Если второй вызов вернул `True` или остаток стал отрицательным, проверка условия стоит после изменения поля. Переставьте строки местами и повторите запуск.

Метод `stock_value()` возвращает стоимость остатка и округляет её через `round(value, 2)`. Проверьте его на товаре с ценой 4.90 и остатком 0: стоимость равна 0.00. Для `SKU-4127` при цене 129.00 и остатке 480 стоимость равна 61920.00. В таблице выводите два знака после точки, иначе `61920.0` и `0.0` разъедутся по ширине столбца.

### Шаг 6. Найдите дефекты в чужом фрагменте

Перед вами класс ячейки хранения из соседней команды. В нём три дефекта: один проявляется при создании двух объектов, второй при размещении товара, третий при неверном количестве. Найдите их, объясните каждый и предложите исправление.

```python
class Cell:
    def __init__(self, code, capacity, occupied=[]):
        self.code = code
        self.capacity = capacity
        self.occupied = occupied

    def place(self, qty):
        if qty > self.capacity:
            return False
        self.capacity =- qty
        return True
```

Проверьте догадку запуском: создайте две ячейки, положите товар в первую и посмотрите, что стало со второй. Затем вызовите `place(0)` и `place(-4)`. Запишите в отчёт, какое правило склада нарушает каждый дефект.

## Критерии оценки

Оценка выставляется по шкале от 1 до 5.

- **5**: класс содержит все поля и методы, конструктор проверяет обязательные значения, методы не меняют состояние при отказе, созданы не меньше четырёх объектов, таблица проверок заполнена фактическими данными, все три дефекта найдены и объяснены.

- **3**: класс создан, однако методы возвращают результат без проверки условий, сценарий содержит меньше четырёх объектов, таблица заполнена частично, дефекты найдены не все.
- **2**: работа не выполнена или класс не запускается.
- **1**: работа выполнена с использованием ИИ или скопирована полностью или частично, 1 балл без возможности исправления.

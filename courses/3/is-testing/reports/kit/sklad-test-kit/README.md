# Учебный комплект «Склад+» для тестирования

Комплект к дисциплине «Тестирование информационных систем» (МДК.05.03).
Внутри сырые требования, шаблоны документов, примеры ответов API и учебная база.
Готовых тест-кейсов, баг-репортов и найденных дефектов нет.

## Состав

- `data/trebovaniya.csv`: 18 требований к учебной ИС, часть сформулирована расплывчато.
- `data/test-cases-template.csv`: пустой шаблон тест-кейсов.
- `data/bug-reports-template.csv`: пустой шаблон баг-репортов.
- `data/api-responses.json`: примеры успешных и ошибочных ответов API.
- `data/sklad.db`: учебная база SQLite с четырьмя площадками, товарами, остатками,
  поставками и строками поставок. В данных есть расхождения, их нужно найти запросами.
- `templates/`: шаблоны отчётов по всем практическим работам.

## Как пользоваться

1. Распакуйте архив в папку занятия, например `.../sklad-test`.
2. Базу открывайте на чтение и не меняйте исходный файл: результаты сохраняйте отдельно.
3. Пути в командах указывайте относительно папки занятия.

## Ограничения

Данные учебные. Совпадения с реальными поставщиками и ценами случайны.

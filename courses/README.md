# Дисциплины

Дерево дисциплин по курсам обучения.

```
courses/
  2/<slug>/                 дисциплины 2 курса
  3/<slug>/                 дисциплины 3 курса
  4/uifis/                  УФИС (МДК.06.03), 4 курс
  _anatomy/                 общий движок фигур Anatomy (не редактировать вручную)
```

Каждая дисциплина описывается файлом `course.json` (см. `courses/4/uifis/course.json`
как образец) и содержит:

- `chapters/<nn-slug>/chapter.md`: текст занятия и папка `figures/<fig-id>/` с фигурой;
- `reports/`: шаблоны отчётов по практическим работам;
- `dist/`: собранные страницы дисциплины (генерируется, не редактировать вручную).

Порядок работы:

1. Создать дисциплину в своём worktree: `python tools/new_discipline.py <year> <slug>`.
2. Заполнить план `course.json` и написать главы по одному занятию.
3. Собрать сайт: `python tools/build_site.py`. Страница курса появится в
   `docs/<year>/<slug>/`, а карточка дисциплины на странице курса `docs/<year>/`.

Сколько лекций и практик открыто для каждой дисциплины, задаёт `availability.txt`
в корне репозитория. Закрытые занятия не собираются и помечаются в плане как закрытые.

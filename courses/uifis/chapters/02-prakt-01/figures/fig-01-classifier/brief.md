# Figure brief: fig-01-classifier

Сортировочный конвейер с тремя поворотными воротцами: карточка проходит последовательно классификацию по сфере применения, по масштабу и по способу обработки и падает в ячейку своего класса.

- **Course / chapter / position:** УФИС · Практика 1 · Fig 1 of the chapter
- **Size:** Figure (one mechanism, 40–80 parts)
- **Reader:** read that an information system can be classified by several independent признаками (сфера, масштаб, способ обработки, архитектура) and must now assign a concrete system to classes.

## The idea it must make obvious
Классификация это не одно название, а несколько независимых признаков: одна и та же ИС проходит через все воротца и получает по классу на каждом признаке.

## Truth (the model)
- inputs: одна учебная карточка ИС за проход. Набор примеров: «Банковская АБС», «1С:Бухгалтерия малого предприятия», «Система диспетчеризации завода», «Интернет-магазин», «Медицинская картотека поликлиники».
- state: три воротца по признакам в порядке: сфера применения, масштаб, способ обработки; на выходе набор ячеек-классов.
- rule: воротца i отклоняет карточку к своей ячейке по значению признака i; значения признаков заданы в `model.mjs` и совпадают с текстом практики.
- concrete values to show:
  - «Банковская АБС»: сфера = финансы, масштаб = корпоративная, способ = оперативная, класс = финансовая корпоративная оперативная ИС.
  - «1С:Бухгалтерия малого предприятия»: сфера = экономика, масштаб = малая, способ = пакетная.
  - остальные примеры заданы в модели с теми же подписями, что в таблице практической работы.
- write this as `model.mjs`; `build.mjs` reads the current card and its three признака from it.

## The object
Ленточный сортировщик на станине: подающий лоток, лента-конвейер, три поворотных воротца на осях со стрелками-указателями признака, за каждым воротцем ячейка-накопитель, по бокам три шкалы с подписями признаков, на торце счётчик рассортированного.

- **What moves, and what that motion means:** лента несёт карточку к воротцам, воротце поворачивается на нужный угол по значению признака и сталкивает карточку в свою ячейку; счётчик увеличивается на каждом отклонении.
- **Mapping:**
  - классифицируемая ИС → карточка на ленте
  - признак классификации → поворотные воротца (по одному на признак)
  - значение признака → угол поворота воротца и номер ячейки
  - набор классов → ряд ячеек-накопителей под каждым воротцем
  - результат классификации → карточка, лежащая в ячейке класса
- **The one lit part:** карточка, которая сейчас на ленте.

## Interaction
- **Pointer:** наведение перебирает карточки примеров.
- **Keyboard:** → следующая карточка, ← назад, Home первая, End последняя.
- **Idle tour:** (1) лента пуста; (2) карточка «Банковская АБС» проходит воротце сферы; (3) воротце масштаба; (4) воротце способа обработки; (5) карточка ложится в ячейку «финансовая корпоративная оперативная»; (6) перезагрузка и следующая карточка.
- **Readout:** `карточка: Банковская АБС · сфера: финансы · масштаб: корпоративная · способ: оперативная`.

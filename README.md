# Материалы дисциплин техникума

Сайт с учебными материалами по специальности 09.02.07 «Информационные системы и
программирование». Структура сайта:

```
главная (специальности и годы) -> год (дисциплины) -> дисциплина (план) -> занятие
```

Сейчас в репозитории 19 дисциплин для 2, 3 и 4 курсов. Полностью написаны и
открыты:

- **УФИС** (МДК.06.03), 4 курс: 39 занятий, лекции с тестами и практики;
- **Управление проектами** (МДК.03.02), 3 курс: 17 занятий;
- **МАПО** (МДК.03.01), 3 курс: 26 занятий;
- **Сертификация информационной системы** (МДК.07.02), 4 курс: 18 занятий;
- **Управление и автоматизация баз данных** (МДК.07.01), 4 курс: 29 занятий,
  MySQL в XAMPP, phpMyAdmin, .NET SDK 10 и Visual Studio 2022;
- **Подготовка к демо-экзамену** (ДЭ-2027), 4 курс: 15 занятий, разбор
  КИМ 09.02.07-5-2027 по шести заданиям.

Остальные дисциплины имеют учебные планы и ждут написания занятий.

## Что есть на странице занятия

- Лекция разбита на 2-4 смысловых блока с воротами. В конце лекции тест из 15
  вопросов: одиночный выбор, множественный выбор и краткий ответ. Типы вопросов
  перемешаны, правильные варианты подсвечиваются только после кнопки «Ответить».
- Практика построена вокруг раздела «Ход работы»: в нём собраны задания, шаги,
  таблицы-шаблоны, проверки и требования к отчёту. После работы идут «Что сдать»,
  критерии и контрольные вопросы без ответов.
- Контрольные вопросы практики нельзя выделить и скопировать: блок отмечен
  `selfcheck no-copy`.
- Скриншоты в практиках нужны только как доказательство работы: вывод команд,
  запросы к базе, ответы API, состояние служб, логи, результаты тестов. Скриншоты
  шапки отчёта, теории и пустых окон не требуются.
- Блоки кода подписаны языком в правом верхнем углу: `powershell`, `python`,
  `sql`, `json`, `bash` и другие.
- На каждой странице есть левая рейка: возврат назад, экспорт в PDF на занятии,
  предупреждение о сбросе прогресса в лекции и переключение темы. На странице
  учебного плана вместо PDF стоит выгрузка плана в Excel.
- Фигуры: Anatomy для механизмов и процессов, где важно движение, и inline SVG
  для схем, иерархий и матриц. Количество фигур не фиксировано, они добавляются по
  необходимости.

Материалы подготовки к ДЭ собраны по открытому разбору
[OlgaKraven/2027-dkip-demo](https://github.com/OlgaKraven/2027-dkip-demo):

Сайт обслуживает специальность 09.02.07 «Информационные системы и
программирование», квалификация «Специалист по информационным системам».
Актуальный КИМ демонстрационного экзамена: КИМ 09.02.07-5-2027, БОМ 6506,
https://bom.firpo.ru/Public/6506.

Проверяются ER-диаграмма в 3НФ, база данных с импортом JSON, SQL-запрос с JOIN и
агрегацией, модули ИС с авторизацией и защитой, GET API, коллекция Postman с
тестами 200/500/JSON и документация API.

Практики опираются только на доступное ПО:

- Excel, Word, PowerPoint;
- VS Code с Python;
- Visual Studio 2022 Community с рабочей нагрузкой .NET desktop;
- Postman;
- XAMPP 8.5.12 с MySQL/MariaDB и phpMyAdmin;
- .NET SDK 10;
- VirtualBox с учебными Linux и Windows 10;
- браузер с draw.io и sqliteonline.com;
- GitHub, Kaggle, Colab и Google Docs;
- PowerShell и терминал Linux.

PlantUML, StarUML, Enterprise Architect, Visio, PyCharm, отдельный сервер MySQL
или PostgreSQL в требованиях не используются. MySQL для МДК.07.01 работает из XAMPP.
Настройки учебных ПК ограничены администратором, поэтому системные работы
выполняются в VirtualBox.

## Структура репозитория

```
courses/
  2/<slug>/                 дисциплины 2 курса
  3/<slug>/                 дисциплины 3 курса
  4/<slug>/                 дисциплины 4 курса
    course.json             план: карточка, результаты, список занятий
    chapters/01-lek-01/     занятие: chapter.md, figures/, при необходимости отчёты
    reports/                шаблоны отчётов и данные
    dist/                   собранные страницы дисциплины
  _anatomy/                 общий движок фигур Anatomy
site.json                   карточки специальностей и курсов для главной
availability.txt            сколько лекций и практик открыто
docs/                       итоговый сайт для GitHub Pages
.opencode/skills/course-studio/   объединённый скилл Course Studio + Anatomy + Visualise
AGENTS.md                   памятка для агента
tools/
  build_site.py             сборка сайта в docs/
  new_discipline.py         создать дисциплину и её worktree
  worktree.py               отдельный git worktree на дисциплину
  ks/                       движок сборки страниц
_reference/miapo/           старые личные заметки, в git не входят
```

## Как добавить дисциплину

Каждая дисциплина разрабатывается в своём worktree и ветке, чтобы несколько
агентов могли работать параллельно.

```powershell
$env:PYTHONUTF8=1
python tools/new_discipline.py 3 otp --title "Основы теории прочности" --code "ОТП"
```

Скрипт создаёт worktree `../mdk-worktrees/3-otp`, ветку `discipline/3/otp` и
`courses/3/otp/course.json`. Заполните план, пишите занятия по одному, коммитьте
в ветке и влейте её в `main`, когда дисциплина готова к публикации.

Отдельно только worktree:

```powershell
python tools/worktree.py add 3 otp
python tools/worktree.py list
python tools/worktree.py remove 3 otp
```

## Доступность занятий

Файл `availability.txt` задаёт, сколько лекций и практик открыто для каждой
дисциплины:

```text
4 курс
Устройство и функционирование информационной системы
    Открытые Лекции = 21
    Открытые Практики = 18

4 курс
Сертификация информационной системы
    Открытые Лекции = 12
    Открытые Практики = 6
```

Занятие открыто, если его порядковый номер среди лекций или практик не больше
указанного числа. Закрытые страницы не собираются в `docs/`, а в плане
дисциплины показывается «закрыто». Если дисциплины нет в файле, открыты все
занятия.

## Локальная сборка

Нужны Python 3.12+, Node.js и зависимости `markdown pygments pyyaml python-docx`.

```powershell
$env:PYTHONUTF8=1
pip install markdown pygments pyyaml python-docx
python tools/build_site.py
```

Отдельное занятие собирается так:

```powershell
python tools/ks/scripts/build_chapter.py courses/4/uifis/chapters/01-lek-01/chapter.md
```

Шаблоны отчётов в `reports/` приводятся к структуре с разделом «Ход работы»,
без полей для ответов и скриншотов шапки, командой:

```powershell
python tools/fix_report_templates.py
```

Фигуры Anatomy собираются в своей папке:

```powershell
cd courses/4/is-certification/chapters/01-lek-01/figures/fig-cert-line
node build.mjs
```

## Проверка страниц

Нужен Playwright и Chromium:

```powershell
pip install playwright
playwright install chromium
```

```powershell
python tools/ks/scripts/check_pages.py courses/4/uifis/dist
python tools/ks/scripts/check_pages.py courses/4/uifis/dist --mobile
python tools/ks/scripts/check_pages.py courses/4/uifis/dist --dark
python tools/ks/scripts/check_pages.py courses/4/is-certification/dist
```

Проверка сообщает об ошибках JavaScript, сломанных ссылках, переполнении по
горизонтали, пустых разделах, незагруженных фигурах и длинных тире. Скриншоты по
умолчанию не делаются: для PNG нужен флаг `--shots`, и они предназначены только
для человека.

## Публикация на GitHub Pages

1. В ветке `main` включите **Settings → Pages → Source: GitHub Actions**.
2. Workflow `.github/workflows/pages.yml` вызовет `python tools/build_site.py` и
   опубликует `docs/`.
3. Итоговый адрес: https://d1m40fficial.github.io/spo-it-materials/.

## Правило оформления

В текстах занятий не используются длинное тире и одиночный дефис как тире.
Проверка страниц и сборка главы сообщают о таких случаях. Сборка детерминирована:
повторный запуск не должен менять `docs/`.

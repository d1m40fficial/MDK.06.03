# Учебный комплект «Склад+»

Комплект к дисциплине «Разработка кода информационных систем» (МДК.05.02).
Внутри сырые данные и шаблоны отчётов. Готовых решений и заполненных таблиц нет.

## Состав

- `data/tovary.csv`: 15 строк каталога товаров, колонки sku, name, category, unit,
  price, stock, site.
- `data/postavki.json`: пять поставок с вложенным списком позиций.
- `data/oshibki.log`: строки журнала за одно утро, уровни INFO, WARN и ERROR.
- `templates/`: шаблоны отчётов по всем практическим работам.

## Как пользоваться

1. Распакуйте архив в папку занятия, например `.../sklad-plus/data`.
2. Файлы данных не редактируйте: результаты сохраняйте в новые файлы.
3. Пути в командах указывайте относительно папки занятия.

## Ограничения

Данные учебные. Совпадения с реальными поставщиками и ценами случайны.

# Учебный комплект «Склад+»

Комплект для практических работ по внедрению информационных систем. Внутри есть учебный прототип ИС, схема базы MySQL, демонстрационные данные и шаблоны отчётов.

Прототип не является промышленной системой. Он показывает роли, заказы, справочники и настройки, чтобы отработать внедрение, обучение, приёмку и поддержку без установки коммерческого продукта.

## Быстрый старт

1. Распакуйте архив в папку работы, например `.../sklad-plus-kit`.
2. Откройте `app/index.html` в браузере. Устанавливать сервер не нужно: данные хранятся в localStorage браузера.
3. Войдите под одной из демонстрационных учётных записей:

| Логин | Пароль | Роль |
|---|---|---|
| `admin` | `admin` | Администратор |
| `manager` | `manager` | Менеджер по продажам |
| `storekeeper` | `storekeeper` | Кладовщик |

4. Для работы с базой откройте `http://localhost/phpmyadmin`, создайте базу `sklad_plus` и импортируйте `database/schema.sql`, затем `database/seed.sql`.

## Состав комплекта

| Папка или файл | Назначение |
|---|---|
| `app/index.html` | Учебный прототип: вход, роли, заказы, номенклатура, пользователи, настройки, экспорт и импорт JSON |
| `database/schema.sql` | Схема MySQL: контрагенты, номенклатура, цены, заказы, склад, пользователи |
| `database/seed.sql` | Демонстрационные данные для схемы |
| `data/customers.csv` | Заказчики для импорта |
| `data/customers.json` | Те же заказчики в JSON |
| `data/orders.csv` | Заказы покупателей |
| `data/order_lines.csv` | Строки заказов |
| `data/prices.csv` | Цены и даты действия |
| `data/notes.csv` | Заметки сотрудников |
| `data/notes.json` | Заметки в JSON |
| `templates/` | Шаблоны отчётов, планов, протоколов и чек-листов |

## Как открыть шаблоны

- Файлы `.docx` открываются в Word или LibreOffice Writer.
- Файлы `.xlsx` открываются в Excel или LibreOffice Calc.
- Файлы `.csv` импортируются в phpMyAdmin на вкладке `Импорт`.
- Файлы `.json` можно открыть в VS Code или загрузить через учебный прототип.

## Что можно делать в прототипе

- Войти под администратором, менеджером или кладовщиком.
- Создать заказ, выбрать склад, товар и количество.
- Изменить статус заказа по маршруту: новый, подтверждён, зарезервирован, отгружен, отменён.
- Администратору добавить пользователя, сменить роль и заблокировать учётную запись.
- Изменить название организации, список складов и статусов.
- Экспортировать данные в JSON и импортировать их обратно.

## Ограничения

- Данные хранятся только в браузере. Очистка данных браузера удалит изменения.
- Пароли демонстрационные и хранятся открыто. Для учебного прототипа это допустимо, для реальной системы так делать нельзя.
- Прототип не связан с MySQL автоматически. База используется отдельно для миграции, копирования и проверки ограничений.
- Перед сбросом демо-данных экспортируйте нужные изменения.
